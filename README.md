## What is HTML?

HTML is the language every web page is written in: a plain text file that tells the browser what's a heading, a paragraph or a button. CSS makes it look good and JavaScript makes clicks do things. Every slide deck and demo here is HTML, made with AI from a prompt. They open in any browser with nothing to install.

## Notes

- All brands, people and figures in the demos are fictional.
- The trip planner's map is drawn from OpenStreetMap data. Map data © OpenStreetMap contributors (ODbL).
- Fonts load from Google Fonts. Icons and charts load from public CDNs, so the demos need an internet connection to look right.
